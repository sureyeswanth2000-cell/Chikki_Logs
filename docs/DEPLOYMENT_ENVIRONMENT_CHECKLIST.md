# Deployment And Environment Checklist

Last updated: 2026-04-29

## Environment Policy
- Local laptop is the development environment.
- GitHub `main` is the shared test/source-of-truth branch.
- Firebase Hosting/Functions/Firestore rules are production.
- Production Firebase deploys must run from GitHub Actions on `main`, not from uncommitted local files.

## Before Merging To `main`
- Run `npm run lint`.
- Run `npm run build`.
- Run `npm run test:security:rules` when Firestore rules or protected data paths changed.
- Confirm `git status --short` has only intentional changes.
- Confirm no secrets are committed. Keep `functions/.env` local or generated by GitHub Actions secrets.

## GitHub Test
- Push the reviewed changes to `main`.
- Let the GitHub Pages `main` workflow build the static app.
- Use the GitHub Pages output as the test surface before production.

## Firebase Production
- Run `Deploy Firebase Hosting (prod)` manually from GitHub Actions on `main`.
- Confirm the workflow uses:
  - Firebase public web config secrets for the static build.
  - `AADHAAR_VAULT_ENCRYPTION_KEY` secret for Functions runtime env generation.
  - `FIREBASE_TOKEN` for Firebase CLI deploy auth.
- Confirm the workflow deploys `hosting`, `functions`, and `firestore:rules` together when backend callables or rules changed.
- After deploy, run `firebase functions:list --project chikki-logs-72607` and confirm required callables are present.
- For the current stabilization release, confirm `submitBookingRating` is listed in `us-central1`.

## Production Smoke Checks
- Open `https://chikki-logs-72607.web.app/Chikki_Logs`.
- Confirm `/Chikki_Logs/login`, `/Chikki_Logs/history`, and `/Chikki_Logs/internal-control` load directly.
- Confirm protected routes redirect correctly when logged out.
- Confirm booking-history rating submits without a browser CORS/preflight error.
- Confirm no raw Aadhaar is visible in normal Firestore-backed profile, booking, owner, operator, or consumer views.
